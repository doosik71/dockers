# dockers

`dockers`는 Docker의 복잡한 기능을 텍스트 콘솔 환경에서도 쉽게 사용할 수 있도록 돕는 Rust 기반 메뉴형 도구이다.

Docker CLI는 강력하지만 명령어, 옵션, 개념이 많아 초보자에게 진입 장벽이 높다. Docker Desktop은 GUI를 통해 이를 완화하지만 기관 환경에서 무료 사용이 제한될 수 있고, 원격 서버나 순수 콘솔 환경에서는 사용하기 어렵다. 이 프로젝트의 목적은 이런 제약을 해결하기 위해 콘솔 안에서 직관적인 메뉴 탐색과 안전한 실행 흐름을 제공하는 것이다.

## 프로젝트 목표

- Docker의 자주 쓰는 기능을 메뉴 기반으로 쉽게 실행할 수 있게 한다.
- GUI 없이도 로컬 콘솔, 원격 터미널, SSH 세션에서 일관되게 사용할 수 있게 한다.
- Windows와 Ubuntu에서 동일한 Rust 소스 코드로 빌드 및 실행할 수 있게 한다.
- 초보자도 컨테이너, 이미지, 볼륨, 네트워크를 실수 없이 다룰 수 있게 한다.
- 파괴적 작업 전 확인 절차와 상태 요약을 제공해 운영 실수를 줄인다.

## 해결하려는 문제

- `docker` 명령어와 옵션 조합이 많아 외우기 어렵다.
- `docker ps`, `docker images`, `docker logs`, `docker exec` 같은 기본 작업도 초보자에게는 탐색 비용이 높다.
- 여러 Docker 리소스를 한눈에 확인하고 작업 흐름을 이어가는 경험이 CLI만으로는 불편할 수 있다.
- 기관 환경에서는 Docker Desktop을 사용하기 어려울 수 있다.
- 서버 환경에서는 GUI 도구보다 텍스트 기반 인터페이스가 더 현실적이다.

## 개발 범위

### 1차 범위

- Docker 엔진 연결 상태 확인
- 컨테이너 목록 조회
- 컨테이너 시작, 중지, 재시작, 삭제
- 컨테이너 로그 조회
- 컨테이너 상세 정보 조회
- 실행 중 컨테이너 쉘 진입
- 이미지 목록 조회 및 삭제
- 볼륨 목록 조회 및 삭제
- 네트워크 목록 조회 및 삭제
- 파괴적 작업 전 확인 프롬프트 제공

### 2차 범위

- 이미지 pull
- 컨테이너 생성 마법사
- 포트, 볼륨, 환경 변수 입력 지원
- 컨테이너 리소스 사용량 조회
- 다중 선택 기반 일괄 작업
- 검색, 필터, 정렬 기능
- 설정 파일 기반 사용자 기본값 저장

### 3차 범위

- Docker Compose 프로젝트 탐색 지원
- 즐겨찾기 작업 저장
- 단축키 중심 고급 탐색
- 작업 이력 및 감사 로그
- 플러그인 또는 확장 구조 검토

## 범위 제외 항목

- Docker Desktop 대체 수준의 완전한 GUI 제공
- Kubernetes 관리 기능
- 클라우드별 컨테이너 서비스 통합
- Docker의 모든 하위 명령 완전 지원
- 웹 브라우저 기반 관리 화면 제공

## 예상 사용자

- Docker 명령어가 익숙하지 않은 개발자
- 원격 서버에서 Docker를 관리해야 하는 운영자
- GUI 사용이 어렵거나 제한된 기관 사용자
- Windows와 Ubuntu를 함께 사용하는 개발 환경

## 제품 방향

`dockers`는 단순히 Docker 명령어를 감싸는 래퍼가 아니라, 사용자가 현재 상태를 이해하고 다음 행동을 안전하게 선택할 수 있도록 돕는 흐름 중심 도구를 지향한다.

예를 들어 다음과 같은 경험을 목표로 한다.

- 메인 메뉴에서 리소스 종류를 선택한다.
- 목록 화면에서 현재 상태를 본다.
- 작업 가능한 명령을 하단 도움말이나 메뉴로 확인한다.
- 위험한 작업은 사전 확인과 요약을 거친다.
- 필요한 경우 내부적으로 적절한 `docker` 명령을 실행하고 결과를 읽기 좋게 보여준다.

## 기술 방향

- 언어: Rust
- 실행 형태: CLI 또는 TUI 기반 콘솔 애플리케이션
- 플랫폼: Windows, Ubuntu
- Docker 연동 방식:
  - 초기 버전은 `docker` CLI 호출 방식 우선 검토
  - 이후 필요 시 Docker Engine API 직접 연동 검토
